## [1.0.0] - 2026-02-08

### Added
- **Prompt Guard v0.1.0** - Prompt injection detection with 95% confidence
- **TX Simulator v0.1.0** - Pre-flight transaction simulation
- **TX Firewall v0.1.0** - Policy enforcement for transactions
- **Security Dashboard v0.1.0** - Unified monitoring web UI
- **Wallet Monitor v0.1.0** - Real-time wallet alerts
- **Honeypot v0.1.0** - Attack pattern detection
- **Reputation Scanner v0.1.0** - On-chain risk assessment
- **Config Manager v0.1.0** - Centralized configuration
- **Agent CLI v0.1.0** - One-line installer for entire stack

### Security
- Defense-in-depth architecture covering 4 layers:
  1. Pre-execution (input validation)
  2. Policy enforcement
  3. Monitoring & detection
  4. Intelligence & risk
